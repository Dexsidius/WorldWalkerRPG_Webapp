# Worldwalker Offline Edition

Extract the complete offline Windows zip and run WorldwalkerOfflinePrototype.exe. Keep _internal alongside it. No AI model, account, typing, or network connection is required for gameplay. WebView2 is required by the Windows window.

Create a character using selections. Choose an activity, review its time/cost, then confirm. Use Living Map and the location selector to review journeys. Actions, work, relationships, mastery, property, expeditions and tactical encounters share the main game rules. Long activities can be interrupted and continued. Save/Load/Export remain available.

Saves use %APPDATA%/WorldwalkerRPGOfflinePrototype, separately from main. Preview 6 saves remain supported. Local stories are finite authored content; comprehensive alternate canon stories and a full generational family simulation remain outside this edition.

See SHARED_EDITIONS.md and BUILD_MANIFEST.json. Both editions now come from the same source commit; continue future work in main Worldwalker.
